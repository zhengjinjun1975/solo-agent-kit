# SoloAgentKit 部署手册

> 本手册面向 FDE（工厂/前置部署工程师）与一人公司：从零装到跑起来，
> 含**模型路由**（本地 ornith ↔ 云端 DeepSeek）说明与常见问题排查。
> 零第三方依赖，只需 Python 标准库。

---

## 一、环境准备

### 1. Python（≥ 3.9）

```bash
python --version        # 需 ≥ 3.9
# 本项目零第三方依赖，无需 venv 也能跑；装进项目内更干净
python -m venv .venv && .venv\Scripts\activate   # Windows
# source .venv/bin/activate                        # macOS / Linux
```

### 2. 安装 solo-agent-kit

```bash
pip install solo-agent-kit        # 或 git clone 后 pip install .
solo version                      # 验证安装
```

### 3. 本地 Ollama（装 ornith + nomic-embed-text）

本地模型跑在 Ollama，快/免费/私有，**无需 API key**。

```bash
# 安装 Ollama：https://ollama.com/download
ollama serve                    # 若未常驻，先启动
ollama pull ornith:latest       # 本地轻量推理模型
ollama pull nomic-embed-text    # 语义嵌入模型（记忆向量检索）
ollama list                     # 确认已装
```

> Windows 安装 Ollama 后默认开机自启，`ollama list` 能列出模型即就绪。

### 4. 云端 DeepSeek key（可选但推荐）

复杂任务升云端，质量更高。去 [platform.deepseek.com](https://platform.deepseek.com) 拿 key：

```bash
# Windows（cmd）：
setx DEEPSEEK_API_KEY "sk-你的key"
# PowerShell：
$env:DEEPSEEK_API_KEY = "sk-你的key"
# macOS / Linux：
echo 'export DEEPSEEK_API_KEY="sk-你的key"' >> ~/.bashrc && source ~/.bashrc
```

> 原则：**key 只进环境变量，不入仓库、不写进任何配置文件**。
> 若没配 key，系统自动全程走本地 ornith，不影响使用。

## 二、模型配置（仿工厂本体风格）

配置在 **`config/model_config.json`**（JSON，仿工厂本体开源风格），仓库内已带默认值，一般**无需改动即可用**：

```jsonc
{
  "_comment": "模型配置：local=本地ornith(Ollama,无需key)，cloud=云端DeepSeek(OpenAI兼容,需api_key)。api_key 留空则读环境变量 DEEPSEEK_API_KEY。",
  "active": "cloud",                      // 默认路由开关：cloud / local
  "routing": {
    "policy": "simple->local ; complex->cloud ; offline->fallback local ; all-down->rule/retrieval",
    "complex_models": ["cloud", "local"],
    "simple_models": ["local"],
    "offline_fallback": true
  },
  "embedding": { "type": "ollama", "base_url": "http://127.0.0.1:11434", "model": "nomic-embed-text" },
  "models": {
    "local":  { "type": "ollama", "base_url": "http://127.0.0.1:11434", "model": "ornith:latest" },
    "cloud":  { "type": "openai", "base_url": "https://api.deepseek.com", "model": "deepseek-chat", "api_key": "" }
  }
}
```

| 字段 | 说明 |
|---|---|
| `active` | 默认路由开关。`cloud` = 复杂任务优先云端；`local` = 一律走本地（离线/省钱） |
| `routing.simple_models` | 简单任务用哪层（默认 `local`，快/免费） |
| `routing.complex_models` | 复杂任务优先哪层（默认 `cloud`，云端不可用自动回退 `local`） |
| `routing.offline_fallback` | 云端离线/无 key/HTTP 错时是否降级本地 |
| `models.local` | 本地 ornith（Ollama） |
| `models.cloud` | 云端 DeepSeek，`api_key` 留空则读 `DEEPSEEK_API_KEY` |
| `embedding` | 记忆向量检索用本地模型 |

**兼容旧配置**：旧版 `provider.yaml`（`provider.local/remote/embed`）仍被支持。代码读取顺序：`config/model_config.json` → `provider.yaml` → `~/.solo/provider.yaml`。

## 三、一键启动

### Web 界面（推荐）

```bash
python solo/web_server.py            # 默认 http://localhost:8743
# 或指定端口：
python solo/web_server.py --port 8743
```

浏览器打开 `http://localhost:8743`，进入各工作区（写作/代码/技能/配置/部署）。

### CLI

```bash
solo setup                             # 部署检查（Python / Ollama / 配置 / 记忆库）
solo config                            # 查看模型配置（脱敏，key 不显示）
solo init                              # 初始化记忆库
solo run "写一篇公众号推文"             # 走完整方法论
solo run "清洗这个 csv" --csv data.csv # 工厂数据清洗
solo factory-onto --csv data.csv       # 工厂本体建模
```

## 四、模型路由说明

**`auto`（默认）** 按任务复杂度智能选层，无需手动指定：

```
任务进来
 ├─ active = local ────────────────→ 一律本地 ornith
 ├─ 简单任务（短问题/点查/计数）──→ 本地 ornith   （省时省钱）
 └─ 复杂任务（>2000字，或含"本体/建模/报告/写一篇/方案"等词）
      ├─ 云端可用 ────────────────→ DeepSeek    （提质量）
      └─ 云端不可用（离线/无key/HTTP错）→ 降级本地 ornith
```

手动强制指定层：`solo run "任务" --tier remote`（云端）或 `--tier local`（本地）。

> 云端无 key / 认证失败是**明确报错**，不静默降级（防止模型编造环境信息）；
> 云端网络不可用则**自动降级本地**。本地也不可用才明确报错。

## 五、常见问题

### Q1：云端没配 key 报错 "未配置 API key"

```bash
setx DEEPSEEK_API_KEY "sk-你的key" && 重启终端
```
或临时改 `config/model_config.json` 的 `models.cloud.api_key` 直接填（会入仓库，不推荐）。

### Q2：Ollama 没起 / 没拉模型

```bash
ollama serve &   # 启动
ollama pull ornith:latest
ollama pull nomic-embed-text
solo setup       # 复查，ollama 项应为 ✅
```
Ollama 未运行时，嵌入检索会回退**词重叠检索**，主功能不受影响。

### Q3：完全离线 / 不想连云端

把 `config/model_config.json` 的 `active` 改为 `local`，全程本地 ornith，零依赖零费用。

### Q4：记忆语义检索不可用

检查 `nomic-embed-text` 是否已拉取。未装时记忆自动回退词重叠检索，不影响对话。

### Q5：复杂任务总是走本地（该升云端没升）

确认 `active = cloud`，且 `routing.complex_models` 含 `cloud`；
确认已设 `DEEPSEEK_API_KEY` 且当前进程能读到（重启终端后 `echo %DEEPSEEK_API_KEY%` 验证）。
