> 版本：0.8.3

---

## 一、同类竞品定位地图

solo-agent-kit 是**独特交叉定位**，没有直接竞品占据同一生态位：

```
        通用AI Agent框架          工业数据平台
        ┌──────────────┐        ┌──────────────┐
        │ LangChain    │        │ IOF本体联盟   │
        │ CrewAI       │        │ Ontop/BaSyx  │
        │ AutoGPT      │        │ 工业FDM工具   │
        │ LlamaIndex   │        │ IEOP(商业)   │
        └──────┬───────┘        └──────┬───────┘
               │                        │
               └─────── 本工具：方法论驱动+零依赖+双场景 ──────┘
                 一人公司个人生产力 + FDE工厂数据/运维
```

**核心差异**：竞品是"框架/平台"（给你地基，自己盖楼），本工具是"方法论驱动的完整套件"（同一套方法论在不同层的落地，零依赖拉下来即用）。

## 五、特点总结（竞品比不上的）

1. **零第三方依赖** — 所有框架都要装几十个包，solo 只用标准库，任何机器拉下来即用
2. **本体建模内置** — 竞品（LangChain/LlamaIndex）全都没有，这是 RAG 的缺失层
3. **"一人公司+FDE工厂"双场景** — 竞品要么做通用 Agent，要么做工业平台，没有同时覆盖
4. **中文工业落地** — 规则+LLM 混合中文问答，换词典即用，本土化
5. **可降级插件体系** — 用不到的不装，装上的必须可靠

---

## 六、诚实声明（对齐定位）

- **社区/生态**远不如竞品（0.8.x vs 10万star成熟框架）
- **工业协议直连**（HART/Modbus）是短板，用 SSH 桥接绕过，Modbus TCP 纯 socket 实现规划中
- **通用性**不如通用框架（聚焦方法论套件，非万能）
