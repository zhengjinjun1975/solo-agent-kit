## 2. 竞品对比（同上次：通用 Agent / 工业本体平台 / IoT 平台 / SaaS MES / Palantir）

| 竞品类别 | 代表 | 核心能力 | 强项 | 弱项 |

### 2.2 solo 差异化定位（同上次，写作补强后更成立）

1. **零依赖 + 离线 + 数据不出厂**（唯一纯标准库全栈，甲方敢用敢自持）——独占优势。
2. **本体优先**（确定性问答先建语义再检索）——对标通用 Agent 的纯 LLM 检索。
3. **交付验收闭环含写作**（需求→SRS→验收→勾稽→**write-qa/write-evidence**→交付包→签收）——对标 MES/监测平台"只有看板没有交付"，且现在报告写作也在链内，交付更完整。
4. **开源原子 + 闭源编排**（Apache-2.0 算法开源，交付增值闭源）。
